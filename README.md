# Awa-Sy-Python-CS
 J’ai réalisé un mandala avec Python Turtle. Le dessin est composé de plusieurs couronnes de pétales de tailles décroissantes, dessinées de la plus grande à la plus petite. Chaque pétale a un contour et un remplissage de couleurs aléatoires grâce au module random. Un cercle rouge entoure le dessin et touche les plus grands pétales. J’ai utilisé des fonctions (petale, couronne), des boucles for et des paramètres pour éviter de répéter le code.
